**The `.cjs` selfchecks need node + jsdom — and they SKIP, loudly-looking-green, without them.** Many pins in `tests/` drive the real shipped JS under jsdom via a Python driver whose gate is `pytest.skip("jsdom not installed")`. Run `npm install` (jsdom + canvas) before trusting a "clean" run. `npm run selfcheck` reports `(N assertions)`, `(silent style)` (legit — `ok()` only speaks on failure), or `ok? … (exit 0 but NO output)` (can't tell asserting-nothing from passing). The harnesses hand Node individual globals (`global.window`, `global.document`, …) rather than a real jsdom script realm — a guard that checks `window.X` while the code *calls* bare `X` throws instead of degrading (the `CSS` global bug, docs/78-era). When adding a harness, bridge every global the code under test reads bare.

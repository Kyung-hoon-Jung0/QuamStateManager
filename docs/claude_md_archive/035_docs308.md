**The UI kit is the one design source (docs/308).** New or changed UI uses only the UI kit (ui-kit.css tokens, _ui.html / ui.js parts, /ui-kit). No new colours, button styles, dialog shells or inline styles; the contract test enforces it: a class with no CSS rule, a new visual rule outside `ui-kit.css`, or a raw value in place of a `--ui-*` token fails `tests/test_ui_contract.py` (debt frozen as per-file ratchets in `tests/ui_contract_baseline.json`, counts only go down). `ui-kit.css` (one `:root` token block of `--ui-*` aliases + `.ui-*` part rules only) is linked right after style.css; `ui.js` is a page bundle (`uikit`), never core; the macro and ui.js trees are parity-pinned by `tests/ui_kit_selfcheck.cjs`.

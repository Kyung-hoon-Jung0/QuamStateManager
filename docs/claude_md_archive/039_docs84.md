**The diff workbench is the front door (docs/84).** `/diff?a=<ref>&b=<ref>&tab=state|wiring|node|data&view=tree|list` is the one comparison surface (tree = the Explorer's `renderJsonTree` with a diff overlay; "Differences only" is a pruned document via `core/json_diff.py`, ranked by |Δ%|, pruned to changed leaves + ancestors). Every legacy comparison entry point (`/compare`, `/chip-compare`, sidebar Compare) redirects into it; the Compare hub sits behind "Advanced…" for entity mapping + N-way baskets. Pinned by `tests/test_diff_workbench.py` + `tests/diff_tree_selfcheck.cjs`.

**One search grammar (docs/96).** space = AND, standalone `|` = OR (tight binding), every other pipe literal. `web/static/search-query.js` + `core/search_query.py` are JS↔PY parity-pinned; wired into tree search, bulk/pair grids, Datasets table, sidebar filter. **A token that NAMES a row wins the row axis (docs/110)** — both grids classify each token as column/id/value with exclusive precedence, so a qubit-id token that also happens to appear in a column's search text no longer gets swallowed as neutral. Pinned by `bulk_search_selfcheck.cjs`.

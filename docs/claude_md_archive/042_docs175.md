Distance to a PREFIX (typing is forward; cost is O(stem × band), not O(name)); OSA transposition makes `mutliplexed`/`wiat_time` distance 1; two prefilters that are valid LOWER bounds (length, and a 32-bit character-presence mask) so neither can reject a true match.

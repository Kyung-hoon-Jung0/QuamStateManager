**Param History: None means none, a filter change swaps only the results (docs/158, 2026-09-03 — customer: "None이면 말그대로 선택하지 않게", "흔들림도 없어야").** The route read an EMPTY selection as "no filter" (`props or DEFAULT`, `qubits or None`), so the None button's request came back as the defaults / every qubit and the whole-root re-render flipped the chips back on. Now the Properties/Qubits rows carry a hidden empty value so the parameter is always PRESENT: presence = explicit (`props=` ⇒ `none_props`, no query, chips unlit, an honest "Nothing selected" line); absence alone = the default view (fresh navigation, Reset filters). The form targets `#param-history-results` with `hx-select` — the form, header and the alignment load-fragment (which re-fetched its banner on every chip click) never re-render; the slow-route loader exempts requests issued from inside `#param-history-filters`; the sparkline afterSwap hook fires on the results swap. CDP-measured: one XHR per press, form node kept, loader never visible, no alignment re-fetch, state survives a reload of the pushed URL.

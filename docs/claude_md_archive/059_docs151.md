**Hovering an Overview tile lists every qubit/pair with its value (docs/151, 2026-09-01).** Compact body-level popup per per-entity tile: heat dot from the tile's OWN cardColor range, id, formatted value, sorted desc, "—" for missing, honest "…and N more" over 48; pointer-events none (never blocks the docs/150 kebab); hides on leave/scroll/re-render/popover. Provenance: the per-edge collectors became id-carrying `*E` variants and the value-only forms are DERIVED from them, so list and aggregate can never disagree. Composite tiles register nothing.

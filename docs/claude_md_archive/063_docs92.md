**Chip topology as a picture (docs/92, plan docs/91).** `TopoGraph.layoutFor` centralizes three honest states: `physical` (only when every node passes a strict grid gate), `logical` (derived from pair connectivity alone, with a visible note), `none` (one honest line, never an invented map). Two maps, one division of labour: the **Chip Status hero map** carries numbers (per-node metric values, edge metrics, hover popup); the **component-page map** (`TopoGraph.renderLayout`/`ComponentMap`) carries no numbers — only structure (stones, pair edges, resonator marks, flux stubs, feedline buses), with map↔table hover binding both ways. Pinned by `tests/topo_graph_selfcheck.cjs` + `chip_status_hero_selfcheck.cjs` + `component_map_selfcheck.cjs`; verified on 8 real chips.

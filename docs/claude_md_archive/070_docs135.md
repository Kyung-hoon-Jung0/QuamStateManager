UI state persisted in `localStorage`: `quam_font_size`, `quam_sidebar_collapsed`, `quam_tray_open`, `quam_split_sizes`, `quam_theme`, `quam_exp_list_compact`, `quam_qualibrate_nav_collapsed`, `recentFolders`, `quam_instrument_fit` (rack Fit/1:1, docs/135 — absent means "decide from the pane width"), `quam_chip_density_panels` (docs/141 §4o, per-panel tile size), `quam_bulk_qhidden:pairs:<chip>` (§4s, the Pairs picker's hidden set), `quam_bulk_fs` + `quam_bulk_col_widths` (the Live-Edit table-size slider and drag-resized columns — both feed the client's virtualization estimate, which is why the server's mirror is pinned, §4ac), `quam_calc_size` (the in-page Calculator's user-set size, docs/141 §4aj) + `quam_calc_win` (the separate Calculator WINDOW's `{w,h,x,y}`, docs/156), and the Live-Edit column sets `quam_bulk_hidden_cols_v2` / `quam_bulk_hidden_cols_pair_v2` / `quam_bulk_dynhidden` (all HIDDEN sets — absent means show everything). `quam_split_user` = the user's last split choice (the sizes of a drag, or which arrow); the old `quam_split_expanded` / `quam_split_collapsed` presets are removed on load (v1.3.0, customer feedback). In **sessionStorage**: `quam_sidebar_compare_sel` (§4y, the compare selection MODEL — not a projection of the tree, see §4ac).

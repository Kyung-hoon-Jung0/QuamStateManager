**The Datasets tree collapses with the arrow keys, and the printout holds every value SM can extract (docs/188, 2026-09-16 — two customer items from one on-site message).** ① **Left / Right** on the Datasets sidebar join the existing Up/Down: Left closes the focused folder, or steps OUT to its parent when it is already closed; Right opens it, or steps IN to the first row inside when it is already open. Two traps paid: `<summary>` is a DESCENDANT of its own `<details>`, so `det.querySelector('summary')` returns the element you started from and steps nowhere (a document-ordered `querySelectorAll` skipping it is the fix), and setting `.open = true` fires `toggle`, which is what keeps docs/142's lazy groups (`hx-trigger="toggle[this.open] once"`) loading. A leaf run opens nothing on Right; a modifier chord is never ours. Pinned by `tests/ds_arrow_nav_selfcheck.cjs` (35 assertions, driven by `test_ds_flow.py`), 3/3 mutations red. ② **The printable report (`GET /chip-status/report`, docs/126 #21) printed nine qubit columns and one pair number** — roughly a third of what the same `QueryEngine` hands every live page. It is thirteen sections now: the one Qubits table split into frequencies / coherence / 1Q gates / readout / readout fidelity, plus flux, QDAC-II bias, the port each channel is cabled to, the pairs, **2Q randomized benchmarking**, 2Q gate parameters, the pair confusion matrix and couplers. Three rules: a column is NEVER dropped because this chip does not fill it (docs/94/docs/148 — an absent column reads as *this chip has no such thing*; a block empty for EVERY entity names the leaf it fills from, e.g. `resonator.gef_confusion_matrix`), while a whole absent INSTRUMENT is the one exception and the QDAC section renders only on a QDAC chip; the report reads the app's OWN derivations (`_topology_with_derived_rb` — the readout fidelities derived from the confusion matrices, the RB level, the Standard-RB-per-gate value — so the printout cannot disagree with Chip Status, wrapped so a raising topology never 500s the page); and there is ONE number renderer, `qty`. **A second renderer was written and caught the same day**: a `%.4f` macro printed a `4.4588e-04` readout threshold as `0.0004`, four significant figures thrown away in a document whose purpose is extraction.

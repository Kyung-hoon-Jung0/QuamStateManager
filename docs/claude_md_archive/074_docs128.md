**Versions panel: per-row Diff + differences-only N-way Compare (docs/128, 2026-08-21).** Every version row carries a read-only **Diff** button — this-version-vs-NOW in the sync review modal's shell + row language (engine: the pre-existing `HistoryManager.diff_current`; NONE of the sync flow's write actions ride along — Pull to Live stays the one gated write, and the note naming it renders only where that button actually exists). Tick-3+ Compare now lands on `/diff/versions`: one row per differing dot-path, one column per version, agreeing leaves never rendered (`Differ.diff_n` — every leaf, per-cell `changed` computed with the row verdict's own equality, docs/118); the Compare hub survives as that page's "Advanced" link. Both new routes pass `ignore_keys=set()` so a class migration (docs/94) is a visible difference rather than a silent one — the page TELLS the user every other leaf agrees, so it must not skip `__class__`; `diff_n` also treats two NaNs as agreeing (docs/118's rule, not a third answer). **Compact means adjacent, not narrow**: the row's actions render between the date and the meta (`margin-left:auto` removed) — the first attempt narrowed the panel 46→36rem instead and that measured as a regression, crushing the docs/126 quick-diff table it shares width with. Two adversarial review rounds (the second a 41-agent red team against the shipped commit: 34 raised, 4 confirmed + 1 from the completeness critic) found 14 defects, all fixed — notably `smModalOpen` not knowing the new overlay (global shortcuts fired behind the modal), a chip-identity gate for two-window races, a stale-response token, an N-way key column collapsing to one character per line, and sticky headers that never stuck.

**The v1.1.0 delivery walk: the ledger is the one history (docs/301, 2026-10-08).** Every surface was clicked in real Chrome on four kinds of chip (a flux-tunable archive, a tunable-coupler archive, an older-stack archive with no `extras`, and chips built from scratch in the Generate wizard); 41 findings, all fixed or decided. Contracts it left: Trends draw a STEP (a stored value holds until its next change; the report too); a point whose writer is not proven opens the run that SAVED it only with `?via=saved`, and that run says it may not be the measurement (`saved_uid` is a separate field from the writer's `uid`, which stays proof-only); Calibration Age is the newer of an entity's `*_updated_at` stamps and its last change by a run (`LedgerTable.run_change_times`: no genesis, no uncertain-chip run, no SM write, since the last rename only), each age naming its basis; the map popup's sparklines, the History (N) drawer, the button and the top-bar Versions count all read the ledger ("unrecorded" stays a snapshot fact); loading an older version keeps the chip's own identity extras (`core/identity_extras.py`); a project whose runs sit directly in the storage location is found by evidence (`hub_sync._holds_runs`), not by the naming rule.

**One history store (S10, docs/302, v1.2.0).** Every surface that shows a value's past (drawer, Column History, agent field history, Chip Status Trends / metric meta / calibration age, Param History grid / drawer / Changes, report, Versions, State History, History drawer, Calibration log) reads the per-chip change ledger (`core/hub_*.py`) through the open folder's view (`hub_lanes`); the old Param History snapshot fallbacks are deleted. Modes: `ledger` / `building` / `preparing` / `unavailable` (one plain sentence, no rows). Param History snapshots stay the capture store (and the lists' older rows). A run leaves a folder's timeline only when its saved state DECLARES another chip. `core/hub_witness.py` judges each run-saved change by the next read of the chip that did not re-measure it (within one rename era) -- a value not in the next recorded state, and an excursion that came back through a save the chip is known to hold, leave every value series and are listed apart; unconfirmed changes are labelled; "since" is where the value's stay on the chip began (measured against a lab's live backups: 98.9% / 96.2% precise). `tests/test_no_undefined_names.py` runs pyflakes over the package.

**Production contracts (v1.3.0, docs/303).** (1) **Host allowlist** (`web/app.py`): a request whose Host is not loopback, the host `qsm serve --host` binds, or a name in `SM_ALLOWED_HOSTS` gets 403 before any route runs (DNS rebinding). (2) **No spawn of an unchosen interpreter**: a GET never runs a Python path SM did not discover or the user did not choose (`config_generator.known_interpreter`); a typed path arrives by an origin-checked POST. (3) **Every JSON body goes through `web/request_body.py`** -- a non-object body or a wrong-typed field is a 400, never a 500 (a route fuzzer over every rule is at 0 real 500s). (4) **htmx `historyCacheSize = 0`**: Back/Forward re-fetch; a localStorage page snapshot (Live State Edit is ~5.6 M characters) only overflowed the quota. Script code that removes htmx-processed markup itself calls `releaseHtmxWithin(root)` first (htmx's own swaps do; a bare `innerHTML = ""` kept `from:body` listeners and the whole pane alive). (5) **Background Datasets scans yield** (`dataset.yielding_scan`, `core/dataset_warm.IndexWarmer`): the poll and the warmer stop at the next 64-run chunk when a request, a history catch-up or the read-index build needs the interpreter; the Datasets page's own scans are never gated. (6) **The ledger's chip is the chip the user opened, named or not** (`routes._hub_live_identity` -> `hub_build.identity_of`); `identity_disagrees` compares a nameless identity part by part (names, else controller, then qubit overlap) and a differing stored seed is replaced with every run judged again (`hub_build.reseed`). (7) **Gate verdicts are keyed by run folder + each input file's (mtime, size)** under `instance/story_cache/gates`, shared by every reader, so they survive a ledger rebuild and a restart. (8) A seam row in a folder view carries the run's own `node.json` patch proof (`hub_lanes._seam_node`). (9) One time window per Trends view and per printable report.

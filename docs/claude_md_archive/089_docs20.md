**Chip identity is a ladder** (docs/20 v2): `state.json`'s top-level `extras["chip_name"]` (user-declared) **>** hardware fingerprint **>** legacy path-derived name, resolved through the single `HistoryManager.resolve_chip_dir` choke point. chip_key = canonical on-disk dir name; pretty names live in `instance/history/_chip_aliases.json` (token-mismatch heals via alignment against the claimed dir's newest sample — only different-network AND different-labels refuses). First open of an unnamed live chip shows a "No chip name is set" banner staging `extras.chip_name` (+ optional `extras.data_folder`) through the working copy only.

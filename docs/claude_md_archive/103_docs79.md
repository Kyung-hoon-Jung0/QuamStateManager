**Env baselines + user verdicts (docs/79):** `core/state_env_baseline.py` records each probe under `instance/state_schema_baselines/<env_key>.json` keyed by env identity, giving class/field diffs across generations. `core/type_verdicts.py` is the user's correction store (`accept` = stop asking / `override` = a TypeSpec stored verbatim), applied as one manifest overlay at the single `load_policy` choke point. Layering: `user(override_env) → verdict → env → user → inference`. Dormant with no verdict file; an accept-all overlay is a provable no-op (golden-pinned).

**Projects** (sidebar, with a toggleable per-project submenu) surfaces the user's `~/.qualibrate` folder — root `config.toml` plus `projects/<name>/config.toml` partial overlays. **Phase 1 is 100% READ-ONLY** (the No-Conflict Doctrine, docs/55) — qualibrate's own root write is non-atomic/unlocked/comment-destroying, so SM must never write these files, pinned by a byte+mtime-identity route test. `core/qualibrate_config.py` owns the reader: `QUALIBRATE_CONFIG_FILE` + `QUAM_STATE_PATH` env semantics, a UI-chosen location override (`instance/qualibrate_location.json`), Windows↔WSL path mapping, 0.1.12 merge fidelity, a `lint` doctor, and `tray_status` (stat-keyed cache). `/qualibrate` is the read-only Config Manager page; `POST /qualibrate/open` is "Open in SM". Topbar `⚗ <project>` badge: red = active project's state_path dangling, amber = SM has a different chip open. See `docs/55_qualibrate_projects.md`.

**Project-centric shell (docs/63).** The project is a lens over the same underlying stores, never a data wall. Sidebar: Projects first, then State Load, then Generate Config; `GET /` is a project-first landing that never auto-activates the last chip. The scope `ctx["qualibrate_project"]` is derived on every activation via a stat-cached reverse index, and pinned by explicit `/qualibrate/open`. History snapshots are stamped with a display-only `SnapshotMeta.project`; Datasets/Trends seed folder selection from `instance/project_dataset_roots.json`. See `tests/test_project_scope.py`.

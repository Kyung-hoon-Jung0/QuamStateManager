**Multi-select, keyboard and tree (docs/234–235; free-edit D-29..D-35).** The grid keeps its same-column selection. In editable Json trees, Ctrl/Cmd+D adds the next equal value (or selected key), Ctrl/Cmd+K then D skips the current occurrence, and Ctrl/Cmd+Shift+L selects all occurrences. Typing opens the shared batch preview. The previous entity-field action is Ctrl+Alt+D / Cmd+Option+D. Ctrl+H / Cmd+Option+F reveals one replace row directly below the existing tree search box, which becomes the find field for the active state or wiring tree; its By path entry retains TreeMulti patterns and arithmetic. SearchQuery supplies the shared AND/OR grammar; case, word, regex and keys toggles are explicit. Counts cover lazy rows, the tree materialises the first 150, and path results are paged with the same budget. Non-empty replacement text previews old → new inline. Enter replaces one, Ctrl+Alt+Enter / Cmd+Option+Enter replaces all. Replacement previews call `/field/replace-preview` (the existing parser and type-policy check, no writes), list skipped pointers/read-only/FSP/type refusals, and render ValueDelta. Apply uses one atomic `/field/edit-batch` group and rejects a stale preview sequence. Key renames use the existing structural rename door. Pinned by `tree_find_selfcheck.cjs`, `tree_free_edit_selfcheck.cjs`, `tree_multi_selfcheck.cjs` and server-backed pytest pins; the Chrome free-edit journey includes find/replace and Cmd+D with server peeks.

**Autofit** (`/autofit`; sidebar label "Auto Calibrate" since r15/docs/69) is the closed calibration loop: one button runs a plan of nodes over chosen targets, gates every fit, LLM-audits residual suspects, reverts rejected node writes deterministically, re-measures with adapted parameters, and reports from an append-only ledger. **Doctrine (docs/47, binding): the LLM never emits a number** — its schema is `{verdict, failure_mode, reason}`; corrections are ①deterministic gates ②CAS'd revert via `patches[].old` ③re-run with family-keyed adaptations; calibration numbers always come from the node's own fitter. `core/autofit/`: `families.py` (metric bands + plausibility/jump limits vs the pre-update anchor + feature x-checks, code-curated), `gates.py` (G1 outcome → G4 physical bands → G3 raw-data x-check → G2 metrics/consistency → G5 history), `auditor.py` (per-plan call budget, numeric emissions discarded+flagged), `engine.py` (per-target decisions, hard-criticality halts only that target's chain), `writer.py` (the ONLY write path: build lock → `batch_set` → `saver.save` → `apply_to_live`), `synth.py`/`simbackend.py` (sim chip + corruption modes, indistinguishable to any SM reader), `realbackend.py` (drives the Scheduler chassis). While a plan runs, the scheduler edit-lock and every `/scheduler/*` route 409. See `docs/56_autofit_scheduler.md` (incl. §7b design-review amendments).

**A press means what the presser could see; a lie in a variable is a lie everywhere (docs/120).** Four mechanisms found driving a real 20-qubit chip in real Chrome. ① **The unseen-edit gate**: two SM windows share one server context and change log, so a tray in window B could be stale while its Apply button still fired on window A's edits — both live-write doors now compare the presser's declared `seen_changes` against the log and 409 `unseen_changes`, naming the paths, with `force=1` and `ack_unseen=1` kept as two separate tokens. ② The app's CSP forbids `unsafe-eval`, so all `hx-on::after-request` handlers were silently dead — replaced with `data-after-request` + one delegated dispatcher. ③ `--topbar-height` was a stale CSS literal versus the real measured height; `window.TopbarHeight` now measures and publishes the truth on load/resize/swap. ④ `live_diverged` now self-refreshes via `_refresh_live_diverged` instead of only on a full render. Grid virtualization gate is now cold-cell-count, not total-cell-count, and per-cell geometry reads are coalesced into one rAF. Pinned across `tests/test_unseen_edits.py` and the extended undo/grid selfchecks.

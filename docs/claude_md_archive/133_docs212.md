**The live write path in RAM: the same bytes, written far sooner (docs/212, 2026-09-27).** Live, working and snapshot docs are parsed once per content digest and validated on every read (`core/doc_cache.py`); file and canonical text are assembled byte-identically from content-addressed subtree pieces (`core/json_pieces.py`); live-diff, drift, snapshot-pair and prev-state diffs are memoized on content tokens; and Apply skips the pull only when live's content hash AND its mtimes are both unmoved. Implementer-measured on big30x, click→written: Apply 22195 → 1684 ms, Keep mine 26038 → 1212 ms, Pull & apply 33639 → 5214 ms, every written file byte-identical to the old code (implementer harness 12/12; the verifier's 23-step A/B harness 23/23 after the D1 re-save fix, run by the fix round). Pinned by `test_json_pieces`, `test_doc_cache`, `test_differ_tree_parity`, `test_diff_cache`, `test_livewrite_cache_parity`, `test_livewrite_fastpaths` (incl. the D1 re-save pin), `test_leaf_patch`.

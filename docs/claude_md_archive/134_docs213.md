**Live Edit grids and the Json Tree patch themselves from a change feed (docs/213, 2026-09-27).** `core/store_revs` records one event per `mutation_seq`, validated on read (an unexplained seq move, or a log that no longer reaches back, means rebuild), and `lint_state`, `analyze_state`, the Live-Edit grids, `get_topology` and the Json Tree text re-derive only what an edit's paths and pointer closures reach; `/bulk` is spliced from cached raw-DEFLATE pieces into one gzip member (`core/gzsplice`) and templates compile at startup. Independent verifier on big30x, base → branch: warm `/bulk` 7287 → 19 ms, Enter repaint 1229 → 130 ms (qubit) / 3702 → 118 ms (pair), 0 stale cells over 202,640 against a cold-recompute oracle; the stated trade-off is a far-right jump on big30x's >20,000-cell grid costing one 3.2-3.6 s long task (base 206-339 ms), a gap no real chip reaches.

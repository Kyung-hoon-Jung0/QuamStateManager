**Pulses: a value commit recomputes only the rows that can see it; a hand-added pulse anywhere gets a row (docs/217, 2026-09-26/27).** `PulseIndex` validates on read against `(mutation_seq, env-overlay object)` and, when every step since is value-only (fed by the one recorder `store_revs.note`, docs/224), recomputes only the rows that see a written path (itself, an ancestor, or a pointer through an alias, transitively); anything else rebuilds cold, and `SM_RAM_VERIFY=1` shadow-checks every incremental result. `/pulse/edit` on big30x: 1701 → 19 ms (implementer), 2461 → 12 ms (independent verifier). Part B (`w7/adaptive`, not merged) finds rows by shape — any classed or aliased `operations` entry, or a pulse-class dict anywhere else, never extras/ports/wiring/network or lists — with whitelisted rows first and byte-identical and an unimportable class never vetoing a row; pinned by `tests/test_pulse_index_ram.py`, `tests/test_pulses_ram_routes.py`, `tests/test_pulse_locations.py` + `tests/golden/pulse_rows_identity.json`, `tests/pulses_urlsync_selfcheck.cjs`.

**A lab's own pulse and gate classes check every write, behind one "+ New pulse" (docs/218, 2026-09-27, `w7/pulsecreate`, not merged).** The env probe adds the lab's own Pulse subclasses, drawn by the class's own `calculate_waveform()` (`core/lab_waveform.py`), and "+ New pulse" offers New pulse / Copy to another channel / Gaussian CZ, filling an empty gate slot the way the chip lays out its gates. Every editing door calls `_lab_write_refusal`: `core/lab_watch.py` follows pointer chains to each lab pulse and lab gate a write reaches and a warm per-env worker runs their own code — a gate is refused only when the edit takes it from applying to failing, and an env that cannot import the class never blocks. Worker: 10.2 / 9.3 s cold → 0.02 s warm (implementer), 9.6-10.8 s cold / 0.02 s warm (independent verifier); Round 4 (the fix for verifier 3's defect, a rename/delete of an op a lab gate plays by name) is pending.

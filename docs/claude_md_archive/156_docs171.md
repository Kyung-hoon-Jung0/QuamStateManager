**The run table survives a restart (docs/171, 2026-09-06).** `DatasetStore(folder, cache_dir=...)` persists what a warm process holds — every `RunInfo` (descriptions interned), `_folder_fp`, `_date_fp` — to `instance/workspace_cache/ds_<sha1>.json` (the docs/142 A′ shape, same doctrine: an accelerator, never a source of truth). A new process loads it and runs the ORDINARY bounded scan, which is the verification: unchanged date dirs cost one stat, changed ones are walked fingerprint by fingerprint, vanished folders drop. Never persisted: mid-write runs, poisoned fingerprints, a truncated walk. Written by a debounced daemon timer off the request path, from a snapshot taken under the scan lock. Measured on the 2,560-run archive: 3.0 s / 29,247 file operations → 0.30 s / 35. Only `_get_or_create_store` wires the instance dir in; direct constructors are byte-identical. Pinned by `tests/test_dataset_store_cache.py`.

The dataset detail page's Data tab is `core/ndview.py` + `web/static/ndview.js`: a generic, crash-free N-D viewer over every variable of every `ds_*.h5` file — dual-format (`_open_reader`, r13/docs/67: NetCDF-classic via scipy, everything else via h5py with `DIMENSION_LIST` deref), name-based dim classification, peak-preserving decimation with click-snap, byte-aware budgets, bytes-caching LRU. `/dataset/<uid>/ndview[/data]` always returns HTTP 200 with classified fallbacks.

**A shot index is not an axis (docs/82).** `_default_view` used to order sweeps by size, and a repetition axis is always the biggest dim in the file, so shot-count dims were being plotted as if they were sweep axes. `_SHOT_DIM_NAMES` (curated from the archive's real names) gives kind `shot`, which is averaged away server-side whenever there is anything else to plot against, and kept only when there is nothing else (e.g. `iq_blobs`' per-shot scatter). Never silent — the controls strip states `averaged over n_runs (2,000 shots)`. Pinned by `tests/test_ndview_repeats.py` + `ndview_selfcheck.cjs`.

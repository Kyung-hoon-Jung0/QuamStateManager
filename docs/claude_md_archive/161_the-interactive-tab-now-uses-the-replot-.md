The Interactive tab now uses the replot path (`core/interactive_plots/replot.py` + `generator/run_interactive_replot.py`) as its default figure source when an environment and saved state are available. Reproduced figures carry per-run learned click contracts; legacy recipes and saved figures remain available where reproduction does not cover them. Recipes (`contracts.py` + `recipes/`) check their formulas against marker evidence, while no-evidence formulas are visibly unverified. `core/click_targets.py` keeps the Data tab's name-bound coordinate candidates. Every click stages through `_openPlotApplyPopup`, `/field/peek` and `/field/edit[-batch]` with the chip-identity gate and optional provenance. See `docs/305_generic_interactive_map_tools.md` and `docs/48_ndview_click_contracts.md`.

**The Interactive panel's four instabilities (docs/118).** A full-page-opened run's Interactive tab was rendering into the wrong pane ID (`#table-pane` vs `#inspector-pane`) so `switchDatasetTab` silently changed nothing; fixed, plus a `ResizeObserver` at both mount points, an offscreen-preferred (not visible-preferred) tile-purge policy, and pin/unpin round-tripping through markup without leaving loaded plots as unrevivable corpses. **One comparison rule**: `differ.compare_equal` is now the single source of truth for both the dataset diff's row-level "is this a difference" decision and the template's cell-level highlight (previously `100` vs `100.0` was flagged as different with nothing highlighted, and `nan` vs `nan` highlighted as a change). Pinned by `tests/test_compare_equality.py` + `tests/interactive_stability_selfcheck.cjs`.

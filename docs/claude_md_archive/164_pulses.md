**Pulses** (sidebar, nested under Live State Edit) is the pulse management surface: every pulse on the chip in one sortable table with server-side SVG sparklines, a detail inspector with instant per-field commit + a live waveform preview (debounced `/api/pulse/synth`), full-catalog create, and delete/rename/duplicate with reverse-pointer (`used_by`) safety. The preview is computed in-process by `core/waveform_synth.py`, pinned bit-for-bit against the customer env by `tests/test_waveform_golden.py`. `core/pulse_catalog.py` is the single source of truth for class schemas/defaults; `core/pulse_index.py` does enumeration + reverse-pointer indexing + pointer rewriting for duplicate/rename. See `docs/40_pulses_page.md`.

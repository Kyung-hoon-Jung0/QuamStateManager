**QDAC-II bias (docs/119).** Some labs flux-bias qubits from an external QDAC-II DC source instead of an OPX LF-FEM port, via the customer's own `quam_config.qdac_components` (imported directly when present). Everything is degrade-only — a missing module or failed trigger allocation leaves that qubit with no z/bias component and a warning, never a crash. The trigger wiring is a second, isolated `Connectivity` (QDAC's custom `"qt"` wiring-line type isn't in the whitelisted builder's vocabulary). `_apply_qdac` reassigns the qubit's runtime `__class__` in place before `apply_populate` runs. Verified end-to-end on a real 20-qubit chip. Pinned by `tests/test_capabilities.py`, `tests/test_config_generator.py::TestValidateSpecQdac`, `tests/test_generate_qdac.py`, `tests/test_generate_qdac_live_build.py`.

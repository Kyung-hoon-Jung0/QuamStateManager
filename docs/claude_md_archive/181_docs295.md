**A renamed qubit is the same qubit (docs/295):** the wizard keeps `{current id: source id}` per row and the build sends it as `qubit_sources`; `regen_merge.rename_source_qubits` re-expresses the source chip in the new ids (keys, pointers, id strings, `_`-delimited ids inside op names; `extras` verbatim) before anything matches by path, and a renamed qubit keeps its port pins. Without the record the merge matches by id, as before.

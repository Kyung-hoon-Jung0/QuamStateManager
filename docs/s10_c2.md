# S10 C2: the folder link offer

C2 adds explicit folder linking through the existing alignment scan and chip decision store. It keeps the later fallback-removal steps separate. `core/hub_sync.py`, `core/hub_store.py`, and existing tests are unchanged.

## Changes

- `core/value_history.py`: `no_folder_linked`, the specified text, and a read-only link offer. Archive-origin contexts suppress the offer.
- `web/routes.py`: one `_hub_root_key`, shared root/label decisions, candidate bucketing and ranking, link/unlink routes, and immediate root registration after an open-chip `same` decision. Explicit root decisions override label decisions.
- `web/hub_status.py`, `web/agent_api.py`: origin-aware notes and JSON offers. The agent API gains no write route.
- `web/templates/_hub_notes.html`: one notes renderer, used by the value drawer, Column History, Trends, grid, Changes, cell drawer, Versions, and State History.
- `web/templates/_hub_link_folder.html`: scan progress, evidence counts, state-folder hints, Link and Unlink forms, and the empty message.
- `web/static/hub-folders.js`, `app.js`, `style.css`, and `templates/base.html`: accessible modal, nested focus handling, error display, scrolling, and refresh on `hubLinked`.
- `web/templates/_state_history.html`: the existing timeline refresh also listens for `hubLinked`.
- `tests/test_hub_link_folder.py`, `tests/hub_link_folder_selfcheck.cjs`: synthetic route, ledger, notes, and actual JavaScript pins.
- `tools/mutate_hub_link_folder.py`: isolated mutations with byte-for-byte restoration. Set `HUB_TEST_ENV` to the test environment before running it. Selected reruns update the combined report.

The eight templates using the shared notes partial are `_field_history_ledger.html`, `_column_history_ledger.html`, `_topo_trends.html`, `_param_history.html`, `_param_history_changes.html`, `_param_history_drawer.html`, `_state_versions.html`, and `_state_history_body.html`.

## Validation

The final regression run passed 856 tests across 26 files, with no failures or skips. `s10_c2_checks.json` records every file and count. Each file runs in a separate process, using the prescribed UTF-8 environment, dependency path, and pytest options. The selected files include every `test_hub_*.py` file, History drawer, Versions, State History, and nearby alignment, agent, column, metric, Trends, and Changes tests. No `test_value_history*.py` files exist in this checkout. The whole suite was not run.

The initial combined regression run had 850 passes and three failures. The Versions click-away failure was caused by this change and was fixed by preserving its original guard and adding a separate folder-modal guard. The Apply-recording and Trends-cache failures disappeared on rerunning both complete files unchanged. The three previously failing cases subsequently passed together with the new pins.

The first key and registration mutations exposed lookup exceptions in new pins. Those pins now explicitly assert that the expected key/root exists; the mutations were rerun to require assertion failures. Existing tests were not edited.

Added lines and new files were checked against the name guard from `origin/main`. The origin test itself is absent from this checkout. The guard was read and executed in memory.

## Spec findings

- There is an additional notes loop in the cell drawer. All eight loops now use the shared partial.
- Alignment also yields a `renamed` bucket, which the three-count design does not map explicitly. These entries count as non-matches in the other-chip bucket and never enable Link.
- The SM-only/no-observed `no_runs` fallback remains for C3. C2's HTML pins use a no-roots ledger with an observed state, so they exercise the offer independently of C1.

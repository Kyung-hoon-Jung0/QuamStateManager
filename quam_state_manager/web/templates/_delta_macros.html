{# Shared Δ (difference) rendering for every before→after surface — docs/76. ONE macro, so the Review tray, the sync/review screen, the diff tables and the history popovers all answer "how much did this change?" the same way. The arithmetic lives in core/value_delta.py (exact decimal, never float noise) and is mirrored character-for-character by window.ValueDelta in app.js for the JS-rendered surfaces (plot-apply popup, bulk grid, FSP). A delta is only rendered when it MEANS something: both sides numeric (or a numeric string — real chips store numbers as text, docs/56 r14). Booleans, nulls, JSON pointers, strings and created/deleted subtrees render nothing, so no surface ever shows a fabricated "0". Usage: {% from '_delta_macros.html' import delta_chip, delta_cell %} {{ delta_chip(old, new) }} → inline chip, empty when meaningless {{ delta_cell(old, new) }} → table cell content, "–" when meaningless #} {% macro delta_chip(old, new, extra_class='') -%} {%- set d = old | value_delta(new) -%} {%- if d -%} {{ d.text }}{% if d.pct_text %} ({{ d.pct_text }}){% endif %} {%- endif -%} {%- endmacro %} {# Compact variant for a NARROW column — docs/186. The full-precision text of a real delta can be 23 characters ("+0.000089381696370544943"), which in the history panel's 99px actions column wrapped over three lines and buried the button it belongs to. Same arithmetic, same title: only the PERCENT is on screen, and the exact number is one hover away. Falls back to the text when there is no percent (a change from zero has no meaningful ratio). #} {% macro delta_pct(old, new, extra_class='') -%} {%- set d = old | value_delta(new) -%} {%- if d -%} {{ d.pct_text or d.text }} {%- endif -%} {%- endmacro %} {# Block variant for the diff/compare tables, where the Δ stacks UNDER the value instead of sitting beside it. Keeps the long-standing .diff-delta class (and its column styling) while using this file's arithmetic, so the same change reads the same everywhere — the diff page used to say "+1.000e+08" where the Review tray says "+100,000,000". #} {% macro delta_block(old, new) -%} {%- set d = old | value_delta(new) -%} {%- if d -%} {{ d.text }}{% if d.pct_text %} ({{ d.pct_text }}){% endif %} {%- endif -%} {%- endmacro %} {# Table-cell variant: always renders something, so a Δ column keeps its alignment (the existing diff tables' convention). #} {% macro delta_cell(old, new) -%} {%- set d = old | value_delta(new) -%} {%- if d -%} {{ d.text }}{% if d.pct_text %} ({{ d.pct_text }}){% endif %} {%- else -%} – {%- endif -%} {%- endmacro %} {# One change row's before -> after (docs/281): the row's op decides the words, so a key that did not exist on one side is never printed as "None". add -> "+ added " gone -> "- removed, was " first -> " first recorded" (the legacy snapshot feed's first point) retarget -> "retargeted -> " (a pointer that names another node) set -> " -> " plus the delta chip above Values print through groupdigits like every other before->after surface; a JSON null prints "null", a list or object as compact JSON. The ledger keeps a scalar list longer than 16 as one value, {"_array": n, "_hash": h} (docs/269): it prints as "[n values]", its content hash in the tooltip. #} {% macro value_text(v) -%} {%- if v is none -%}null {%- elif v is mapping and v|length == 2 and '_array' in v and '_hash' in v -%}[{{ v._array }} values] {%- elif v is mapping or (v is iterable and v is not string) -%}{{ v | tojson }} {%- else -%}{{ v | groupdigits }}{%- endif -%} {%- endmacro %} {% macro before_after(old, new, op='set') -%} {%- if op == 'add' -%} + added {{ value_text(new) }} {%- elif op == 'gone' -%} − removed was {{ value_text(old) }} {%- elif op == 'first' -%} {{ value_text(new) }} first recorded {%- else -%} {%- if op == 'retarget' %}retargeted {% endif -%} {{ value_text(old) }} → {{ value_text(new) }}{{ delta_chip(old, new) }} {%- if old is mapping and new is mapping and '_hash' in old and '_hash' in new %} contents changed{% endif -%} {%- endif -%} {%- endmacro %}

Export

Export CSV sits above the Qubits, Pairs and Resonators tables and in Live state edit (table view) (the columns you see). For any set of columns, use the Parameter table. The printable chip report downloads as HTML.

Environment upgrade report

What it compares. The Environment match card in Diagnostics compares the Python environment selected now with the one this chip was last checked in.

What it lists. Fields that no longer exist, renamed or moved fields, changed class signatures, lab classes that no longer match, and waveforms that differ from a recorded reference.

What it changes. Stage reviewed changes puts the reviewed renames and removals in the Review tray. Nothing reaches the chip until you apply it. The card's last line says what is not checked.

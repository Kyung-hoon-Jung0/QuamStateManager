QUAM State Manager — feature guide

See, edit, compare and track a superconducting-qubit chip's QUAM state, with its experiment runs beside it. Each feature below is one line and one screenshot (a synthetic 17-qubit demo chip). Click a row to open it.

Install into your lab env: pip install "git+https://github.com/Kyung-hoon-Jung0/QuamStateManager.git@v1.5.4", then run qsm browser. Details and troubleshooting in the README.
Chip StatusThe whole chip on one screen, read straight from your state file.7
OverviewHeadline numbers: gate and readout fidelities, RB coverage, how many qubits are in spec.
HealthWhat needs attention first: qubits below spec, stale calibrations, structural issues.
TopologyThe chip map from your wiring, with frequencies, anharmonicities and pair detunings.
TrendsHow T1, T2, fidelities or any parameter moved over time, per qubit, from the recorded runs.
FidelitiesHeatmap + ranked bars for 1Q, 2Q and readout fidelity, coherence and frequencies.
Z-line distortionThe exponential and FIR filters on each flux port, and what they do to a flux pulse.
CZ gate planWhere each CZ moves its qubits in frequency and which lines it crosses on the way.
Live State EditEdit any value like a spreadsheet; edits stay in a working copy until you apply them.3
GridEvery qubit parameter in one grid: type, fill down (Ctrl+D), paste a column, undo with Ctrl+Z.
Json TreeThe full state and wiring as a searchable tree with pointers resolved; edit any leaf in place.
PulsesEvery pulse with its waveform; create, rename, duplicate or edit and watch the shape update.
DatasetsYour experiment runs next to the chip they calibrated.5
Run listAll runs in a data folder, grouped by experiment, filterable by qubit, tag or date.
Run detailParameters, fit results, figures and the state each run wrote, with a diff to the run before.
Interactive plotsExplore the raw data cube, smooth or fit it, and click a point to stage that value.
TrendsPick an experiment and see its fit results across every run, per qubit.
CollectionsThe runs you starred or tagged, in one list.
State HistoryEvery recorded state of the chip, and what changed between them.3
State HistorySnapshots over time: see what changed, load one for review, or restore it to the live chip.
Param HistoryEvery parameter change with its before, after and the run that wrote it.
Versions + DiffAny recorded version against now, value by value; accept a row to bring it back.
Sync & Apply to liveThe live chip is written only when you press Apply to live, and that press can be undone.2
Pending editsEdited cells stay marked until applied; the top bar counts them.
Review trayEvery pending change with before, after and delta; apply to live, take live, discard, or undo.
Instrument Wiring1
Instrument WiringThe instrument rack with every port and what drives it: XY, readout, flux.
Chip ComponentsTables of the chip's parts, each next to its own map.4
QubitsOne row per qubit with the parameters you look at most.
PairsQubit pairs with control/target, CZ amplitude and fidelity.
ResonatorsReadout resonators grouped by feedline.
FluxFlux lines with offsets, flux points and delays.
Diagnostics1
DiagnosticsChecks on state and wiring that would break a run, each with a jump to the field and a fix.
Compare1
CompareAny two or three versions side by side: differences only, with the delta of every value.
Generate / Re-generate ConfigBuild a chip's QUAM files, or rebuild them without losing calibration.3
Generate ConfigA step-by-step wizard: environment, instrument, qubits, wiring, then a fresh state + wiring.
Re-generate ConfigChange a chip's structure and rebuild it while keeping every calibrated value.
Config ViewerPreview the exact QM config your experiments will get from this state.
Calculator1
CalculatordBm, volts and amplitude conversions and RF = LO + IF, one click away in the sidebar.
Agent1
AgentAsk your own Claude Code or Codex about the chip; nothing runs or writes without your press.
